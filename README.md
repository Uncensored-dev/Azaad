## 📖 Overview

**AZAAD** is a lightweight, censorship-resistant mobile application built to provide direct, unblockable public access to landmark investigative documentaries subjected to emergency blocking orders under Section 69A of India's Information Technology Act and the IT Rules 2021.

When governments issue emergency takedown orders to YouTube, Twitter/X, and social media platforms, public interest journalism often disappears from public view. AZAAD uses decentralized cloud mirrors (including Mega.nz and independent video CDNs) inside a secure WebView wrapper to ensure continuous access to crucial historical and political records.

## ⚖️ Constitutional & Legal Basis

The right to receive and impart information is a recognized fundamental right under:
1. **Article 19(1)(a) of the Constitution of India**: Guarantees Freedom of Speech and Expression, which the Supreme Court of India has repeatedly held includes the right of citizens to know, read, watch, and receive diverse viewpoints and journalistic works.
2. **Article 19 of the Universal Declaration of Human Rights (UDHR)**: *"Everyone has the right to freedom of opinion and expression; this right includes freedom to hold opinions without interference and to seek, receive and impart information and ideas through any media and regardless of frontiers."*
3. **Article 19 of the International Covenant on Civil and Political Rights (ICCPR)**.

This repository serves strictly as an educational, journalistic, and historical archive in the public interest.

## 🚀 Running the App Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm or bun
- Expo Go on Android / iOS or Android Studio / Xcode for native development

### Installation
```bash
git clone https://github.com/your-username/docustream.git
cd docustream
npm install
```

### Launch Development Server
```bash
npx expo start
```
- Press `a` for Android Emulator / connected device
- Press `w` for Web browser
- Or scan the QR code using the **Expo Go** mobile app

### Production Build (APK / AAB)
